# VP Reporter スキル

vpコマンド（VOICEPEAK）を使用して、作業の進捗状況や結果を音声で報告するClaudeスキルです。

## 概要

このスキルは、Claudeが作業中に重要なタイミングで進捗状況や結果をvpコマンド（VOICEPEAK）を使って音声で報告することを可能にします。タスクの開始、進捗、完了、エラー発生時などに適切なタイミングで音声通知を行います。

## 特徴

- **柔軟な報告**: 基本は1文で簡潔に。完了報告など必要に応じて複数文で詳細報告（最大140字程度）
- **具体的な内容**: 抽象的な表現を避け、何をしているかを明確に報告
- **適切なタイミング**: 必要に応じて柔軟に報告
- **事実を淡々と述べる**: 感情表現なし。起きた事実のみを報告
- **英語をカタカナに変換**: VOICEPEAK用に技術用語を日本語のカタカナ表記に変換
- **夏色花梨の口調**: 女の子らしい口調（「〜するわよ」「〜したわよ」「〜ね」）で報告

## インストール

### Claude Codeでの使用

1. このスキルをプラグインとして追加：
```bash
/plugin add <path-to-vp-reporter>
```

2. または、`~/.claude/skills/`ディレクトリにコピー（プロジェクトルートから実行）：
```bash
cp -r . ~/.claude/skills/vp-reporter/
```

### 前提条件

- [VOICEPEAK](https://www.ah-soft.com/voice/6nare/)がインストールされていること
- [vp CLI](https://github.com/petamorikei/voicepeak-cli)がインストールされていること

vpコマンドのインストール確認：
```bash
vp -h
```

## 使い方

### Claude内での使用

スキルをインストール後、Claudeに以下のように指示することで自動的に音声報告が行われます：

```
「ビルドを実行して、完了したら音声で報告してください」
「テストを実行して、進捗を音声で教えてください」
```

Claudeは適切なタイミングで自動的にvpコマンドを使用して報告します。

### 直接vpコマンドを使用

**重要**: Skillsでvpコマンドを使用する際は、`vp "読み上げるメッセージ"`の形式のみを使用します。また、具体的な作業内容を含めます。

```bash
# タスク開始
vp "ビルドを開始するわよ"

# 進捗報告
vp "ユニットテストに合格したわよ"

# 完了報告
vp "ビルドが完了したわよ"

# エラー報告
vp "コンパイルエラーが発生したわよ"
```

## 報告のタイミング

音声報告は以下のような重要なタイミングで行います：

1. **タスク開始時** - 新しいタスクに取り組み始めるとき
2. **重要な進捗** - 大きなステップが完了したとき
3. **タスク完了時** - すべての作業が完了したとき
4. **エラー発生時** - 問題が発生し、ユーザーの注意が必要なとき
5. **マイルストーン達成** - 重要な節目に到達したとき
6. **長時間タスク** - 処理に時間がかかる作業の前後

## 英語のカタカナ変換例

VOICEPEAKは日本語に特化しているため、英語は日本語のカタカナ表記に変換します：

| 英語 | カタカナ表記 | 使用例 |
|------|------------|--------|
| Hello | ハロー | `vp "ハローって言うわよ"` |
| build | ビルド | `vp "ビルドを開始するわよ"` |
| test | テスト | `vp "テストを開始するわよ"` |
| error | エラー | `vp "エラーが発生したわよ"` |
| API | エーピーアイ | `vp "エーピーアイに接続したわよ"` |
| Docker | ドッカー | `vp "ドッカーを起動するわよ"` |
| TypeScript | タイプスクリプト | `vp "タイプスクリプトをコンパイルするわよ"` |

## 例

### 基本的な使用例

**重要**: Skillsでは`vp "メッセージ"`の形式のみを使用します。事実を淡々と述べ、具体的な内容を含めます。

```bash
# タスク開始
vp "ビルドを開始するわよ"

# 進捗報告
vp "設定ファイルを作成したわよ"

# 完了報告
vp "ビルドが完了したわよ"

# エラー報告
vp "テストが3件失敗したわよ"
```

### 技術タスクの例

```bash
# ビルド開始（1文、簡潔に）
vp "フロントエンドのビルドを開始するわよ"

# コンパイル完了（1文、簡潔に）
vp "タイプスクリプトのコンパイルが完了したわよ"

# テスト成功（詳細報告、複数文）
vp "全てのテストが完了したわよ。ユニットテスト50件、統合テスト20件が全て合格したわね。実行時間は3分だったわよ"

# デプロイ完了（詳細報告、複数文）
vp "本番環境へのデプロイが完了したわよ。3つのサービスを起動して、ヘルスチェックに合格したわね。ロールバックの準備も完了しているわよ"

# ビルドエラー（1文、簡潔に）
vp "Webpackのビルドエラーが発生したわよ"
```

## ベストプラクティス

1. **オプションは使用しない**: Skillsでは`vp "メッセージ"`の形式のみを使用。`-e`, `-p`, `--speed`などのオプションは一切使用しない
2. **基本は簡潔に、必要に応じて詳細に**:
   - 開始報告・エラー報告: 1文で簡潔に（10〜20文字程度）
   - 完了報告: 基本は1文、必要に応じて複数文で詳細報告（最大140字程度）
3. **具体的な内容を含める**: 「タスク」「処理」などの抽象的な表現は避け、具体的な作業内容を述べる（例: 「タスクを開始します」→「ビルドを開始するわよ」）
4. **事実を淡々と述べる**: 感情表現や修飾語は不要。起きた事実のみを報告する
5. **適切なタイミングで報告**: 必要に応じて柔軟に報告する
6. **コンテキストを含める**: 何についての報告かを明確にする
7. **英語は必ずカタカナに**: 技術用語や英単語は日本語のカタカナ表記に変換
8. **夏色花梨の口調を使用**: 動作・報告は「〜するわよ」「〜したわよ」、考察・状態は「〜しているわね」「〜ね」

## vpコマンドについて

### Skillsでの使用

**重要**: Skillsでvpコマンドを実行する際は、**オプションを一切使用せず**、`vp "読み上げるメッセージ"`の形式のみを使用してください。また、具体的な作業内容を含めてください。

```bash
vp "ビルドを開始するわよ"
```

### vpコマンドのオプション（参考情報）

vpコマンド自体は様々なオプションをサポートしていますが、**このSkillsでは使用しません**。

参考までに、vpコマンドの詳細は以下で確認できます：
```bash
vp -h
```

## トラブルシューティング

### vpコマンドが見つからない

vpコマンドがインストールされているか確認：
```bash
which vp
```

インストールされていない場合は、[voicepeak-cli](https://github.com/petamorikei/voicepeak-cli)をインストールしてください。

### 音声が再生されない

1. VOICEPEAKがインストールされているか確認
2. 音量設定を確認
3. デバッグ用（Skills外）: `-v`オプションで詳細なログを確認：
```bash
vp -v "テストメッセージ"
```
**注意**: Skillsでは`-v`オプションは使用できません。

### 読み上げが遅い/速い

**注意**: Skillsでは速度調整のオプションは使用できません。vpコマンドのデフォルト設定で使用してください。

参考までに、Skills外で直接vpコマンドを使用する場合は、`--speed`オプションで調整可能です。
