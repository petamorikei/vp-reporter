# タスク開始時の報告例

タスクを開始する際の音声報告の例です。大きなタスクの開始だけでなく、サブタスクや小さなステップの開始時にも報告します。

## 基本的な開始報告

**重要**: 「タスク」「作業」「処理」などの抽象的な表現は避け、具体的な作業内容を述べます。

```bash
vpsay "ビルドを開始するわよ"
vpsay "テストを実行するわよ"
vpsay "デプロイを開始するわよ"
vpsay "コンパイルを開始するわよ"
vpsay "データベースマイグレーションを開始するわよ"
```

## より詳細な開始報告

```bash
vpsay "フロントエンドのビルドを開始するわよ"
vpsay "ユニットテストを実行するわよ"
vpsay "本番環境へのデプロイを開始するわよ"
vpsay "タイプスクリプトのコンパイルを開始するわよ"
```

## 長時間かかる処理の開始報告

```bash
vpsay "大規模ビルドを開始するわよ"
vpsay "全テストスイートを実行するわよ"
vpsay "データベースのバックアップを開始するわよ"
```

## サブタスク・小さなステップの開始報告

大きなタスクを細かく報告する場合：

```bash
# ビルドタスクの各ステップ
vpsay "依存関係の確認を開始するわよ"
vpsay "ソースファイルの読み込みを開始するわよ"
vpsay "タイプチェックを開始するわよ"
vpsay "トランスパイルを開始するわよ"
vpsay "バンドルの作成を開始するわよ"

# テストタスクの各ステップ
vpsay "テスト環境のセットアップを開始するわよ"
vpsay "ユニットテストの実行を開始するわよ"
vpsay "統合テストの実行を開始するわよ"

# ファイル操作
vpsay "設定ファイルの読み込みを開始するわよ"
vpsay "ログファイルの作成を開始するわよ"
```
