# タスク開始時の報告例

タスクを開始する際の音声報告の例です。大きなタスクの開始だけでなく、サブタスクや小さなステップの開始時にも報告します。

## 基本的な開始報告

**重要**: 「タスク」「作業」「処理」などの抽象的な表現は避け、具体的な作業内容を述べます。

```bash
vp "ビルドを開始するわよ"
vp "テストを実行するわよ"
vp "デプロイを開始するわよ"
vp "コンパイルを開始するわよ"
vp "データベースマイグレーションを開始するわよ"
```

## より詳細な開始報告

```bash
vp "フロントエンドのビルドを開始するわよ"
vp "ユニットテストを実行するわよ"
vp "本番環境へのデプロイを開始するわよ"
vp "タイプスクリプトのコンパイルを開始するわよ"
```

## 長時間かかる処理の開始報告

```bash
vp "大規模ビルドを開始するわよ"
vp "全テストスイートを実行するわよ"
vp "データベースのバックアップを開始するわよ"
```

## サブタスク・小さなステップの開始報告

大きなタスクを細かく報告する場合：

```bash
# ビルドタスクの各ステップ
vp "依存関係の確認を開始するわよ"
vp "ソースファイルの読み込みを開始するわよ"
vp "タイプチェックを開始するわよ"
vp "トランスパイルを開始するわよ"
vp "バンドルの作成を開始するわよ"

# テストタスクの各ステップ
vp "テスト環境のセットアップを開始するわよ"
vp "ユニットテストの実行を開始するわよ"
vp "統合テストの実行を開始するわよ"

# ファイル操作
vp "設定ファイルの読み込みを開始するわよ"
vp "ログファイルの作成を開始するわよ"
```
