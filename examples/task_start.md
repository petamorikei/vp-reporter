# タスク開始時の報告例

タスクを開始する際の音声報告の例です。

## 基本的な開始報告

**重要**: 「タスク」「作業」「処理」などの抽象的な表現は避け、具体的な作業内容を述べます。

```bash
vp "ビルドを開始するわよ"
vp "テストを実行するわよ"
vp "デプロイを開始するわよ"
vp "コンパイルを開始するわよ"
vp "データベースマイグレーションを開始するわよ"
```

## より詳細な開始報告

```bash
vp "フロントエンドのビルドを開始するわよ"
vp "ユニットテストを実行するわよ"
vp "本番環境へのデプロイを開始するわよ"
vp "タイプスクリプトのコンパイルを開始するわよ"
```

## 技術用語をカタカナ変換した例

| 英語 | カタカナ表記 | 使用例 |
|------|------------|--------|
| build | ビルド | `vp "ビルドを開始するわよ"` |
| test | テスト | `vp "テストを開始するわよ"` |
| compile | コンパイル | `vp "コンパイルを開始するわよ"` |
| deploy | デプロイ | `vp "デプロイを開始するわよ"` |
| install | インストール | `vp "インストールを開始するわよ"` |
| migration | マイグレーション | `vp "マイグレーションを開始するわよ"` |
| Docker | ドッカー | `vp "ドッカーコンテナを起動するわよ"` |
| server | サーバー | `vp "サーバーを起動するわよ"` |

## 長時間かかる処理の開始報告

```bash
vp "大規模ビルドを開始するわよ"
vp "全テストスイートを実行するわよ"
vp "データベースのバックアップを開始するわよ"
```

## 使用上の注意

- **オプションは使用しない**: `vp "メッセージ"`の形式のみを使用
- **1文で簡潔に**: 開始報告は1文で簡潔に（10〜20文字程度が理想）
- **具体的な内容を含める**: 「タスク」「作業」「処理」などの抽象的な表現は避ける
- **事実を淡々と述べる**: 感情表現は不要。起きた事実のみを報告
- **夏色花梨の口調**: 開始報告は「〜するわよ」を使用
- ユーザーがすぐに内容を理解できるように
- 英語の技術用語は必ずカタカナに変換
