# 進捗報告の例

作業の進捗状況を報告する際の音声報告の例です。小さなステップが完了するたびに報告します。

## 基本的な進捗報告

**重要**: 抽象的な表現は避け、具体的な作業内容を述べます。

```bash
vpsay "コンパイルが完了したわよ"
vpsay "ビルドが半分完了したわよ"
vpsay "エーピーアイ接続に成功したわよ"
vpsay "パッケージのインストールが完了したわよ"
```

## より詳細な進捗報告

```bash
vpsay "設定ファイルを作成したわよ"
vpsay "データベース接続に成功したわよ"
vpsay "ユニットテストに合格したわよ"
vpsay "依存関係のインストールが完了したわよ"
```

## 段階的な進捗報告

```bash
vpsay "コンパイルが完了したわよ"
vpsay "テストが完了したわよ"
vpsay "パッケージングを開始するわよ"
```

## 数値を含む進捗報告

```bash
vpsay "テストが5件完了したわよ"
vpsay "ビルドが80パーセント完了したわよ"
vpsay "残り3ファイルよ"
```


## 複雑な処理の進捗報告

```bash
vpsay "データベースマイグレーションが完了したわよ"
vpsay "ノードモジュールのインストールが完了したわよ"
vpsay "統合テストが成功したわよ"
vpsay "エーピーアイの統合が完了したわよ"
```

## 細かいステップの進捗報告

1つの大きなタスク内の小さなステップを報告する場合：

```bash
# ビルドの各ステップの完了
vpsay "依存関係の確認が完了したわよ"
vpsay "ソースファイルの読み込みが完了したわよ"
vpsay "タイプチェックが完了したわよ"
vpsay "トランスパイルが完了したわよ"
vpsay "バンドルの作成が完了したわよ"

# テストの各ステップの完了
vpsay "テスト環境のセットアップが完了したわよ"
vpsay "ユニットテスト10件が完了したわよ"
vpsay "ユニットテスト20件が完了したわよ"
vpsay "統合テスト5件が完了したわよ"

# ファイル操作の完了
vpsay "設定ファイルの読み込みが完了したわよ"
vpsay "ログファイルの作成が完了したわよ"
vpsay "出力ファイルの書き込みが完了したわよ"
```
