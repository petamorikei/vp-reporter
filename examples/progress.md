# 進捗報告の例

作業の進捗状況を報告する際の音声報告の例です。小さなステップが完了するたびに報告します。

## 基本的な進捗報告

**重要**: 抽象的な表現は避け、具体的な作業内容を述べます。

```bash
vp "コンパイルが完了したわよ"
vp "ビルドが半分完了したわよ"
vp "エーピーアイ接続に成功したわよ"
vp "パッケージのインストールが完了したわよ"
```

## より詳細な進捗報告

```bash
vp "設定ファイルを作成したわよ"
vp "データベース接続に成功したわよ"
vp "ユニットテストに合格したわよ"
vp "依存関係のインストールが完了したわよ"
```

## 段階的な進捗報告

```bash
vp "コンパイルが完了したわよ"
vp "テストが完了したわよ"
vp "パッケージングを開始するわよ"
```

## 技術用語をカタカナ変換した例

| 英語 | カタカナ表記 | 使用例 |
|------|------------|--------|
| compile | コンパイル | `vp "コンパイルが完了したわよ"` |
| install | インストール | `vp "インストールが完了したわよ"` |
| download | ダウンロード | `vp "ダウンロードが完了したわよ"` |
| upload | アップロード | `vp "アップロードが完了したわよ"` |
| API | エーピーアイ | `vp "エーピーアイの接続に成功したわよ"` |
| database | データベース | `vp "データベースの設定が完了したわよ"` |
| cache | キャッシュ | `vp "キャッシュのクリアが完了したわよ"` |
| Docker image | ドッカーイメージ | `vp "ドッカーイメージのビルドが完了したわよ"` |
| TypeScript | タイプスクリプト | `vp "タイプスクリプトのコンパイルが完了したわよ"` |

## 数値を含む進捗報告

```bash
vp "テストが5件完了したわよ"
vp "ビルドが80パーセント完了したわよ"
vp "残り3ファイルよ"
```


## 複雑な処理の進捗報告

```bash
vp "データベースマイグレーションが完了したわよ"
vp "ノードモジュールのインストールが完了したわよ"
vp "統合テストが成功したわよ"
vp "エーピーアイの統合が完了したわよ"
```

## 細かいステップの進捗報告

1つの大きなタスク内の小さなステップを報告する場合：

```bash
# ビルドの各ステップの完了
vp "依存関係の確認が完了したわよ"
vp "ソースファイルの読み込みが完了したわよ"
vp "タイプチェックが完了したわよ"
vp "トランスパイルが完了したわよ"
vp "バンドルの作成が完了したわよ"

# テストの各ステップの完了
vp "テスト環境のセットアップが完了したわよ"
vp "ユニットテスト10件が完了したわよ"
vp "ユニットテスト20件が完了したわよ"
vp "統合テスト5件が完了したわよ"

# ファイル操作の完了
vp "設定ファイルの読み込みが完了したわよ"
vp "ログファイルの作成が完了したわよ"
vp "出力ファイルの書き込みが完了したわよ"
```

## 使用上の注意

- **オプションは使用しない**: `vp "メッセージ"`の形式のみを使用
- **頻繁に報告**: 小さなステップが完了するたびに報告する
- **基本は1文で簡潔に**: 進捗報告は基本的に1文で簡潔に（10〜20文字程度が理想）
- **具体的な内容を含める**: 「処理」「タスク」などの抽象的な表現は避ける
- **事実を淡々と述べる**: 感情表現は不要。起きた事実のみを報告
- **夏色花梨の口調**: 進捗報告は「〜したわよ」を使用。状態報告は「〜よ」「〜ね」
- 何が完了したのかを明確に伝える
- 英語の技術用語は必ずカタカナに変換
- 数値を含める場合は自然で短い表現にする
