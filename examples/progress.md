# 進捗報告の例

作業の進捗状況を報告する際の音声報告の例です。小さなステップが完了するたびに報告します。

## 基本的な進捗報告

**重要**: 抽象的な表現は避け、具体的な作業内容を述べます。

```bash
vp "コンパイルが完了したわよ"
vp "ビルドが半分完了したわよ"
vp "エーピーアイ接続に成功したわよ"
vp "パッケージのインストールが完了したわよ"
```

## より詳細な進捗報告

```bash
vp "設定ファイルを作成したわよ"
vp "データベース接続に成功したわよ"
vp "ユニットテストに合格したわよ"
vp "依存関係のインストールが完了したわよ"
```

## 段階的な進捗報告

```bash
vp "コンパイルが完了したわよ"
vp "テストが完了したわよ"
vp "パッケージングを開始するわよ"
```

## 数値を含む進捗報告

```bash
vp "テストが5件完了したわよ"
vp "ビルドが80パーセント完了したわよ"
vp "残り3ファイルよ"
```


## 複雑な処理の進捗報告

```bash
vp "データベースマイグレーションが完了したわよ"
vp "ノードモジュールのインストールが完了したわよ"
vp "統合テストが成功したわよ"
vp "エーピーアイの統合が完了したわよ"
```

## 細かいステップの進捗報告

1つの大きなタスク内の小さなステップを報告する場合：

```bash
# ビルドの各ステップの完了
vp "依存関係の確認が完了したわよ"
vp "ソースファイルの読み込みが完了したわよ"
vp "タイプチェックが完了したわよ"
vp "トランスパイルが完了したわよ"
vp "バンドルの作成が完了したわよ"

# テストの各ステップの完了
vp "テスト環境のセットアップが完了したわよ"
vp "ユニットテスト10件が完了したわよ"
vp "ユニットテスト20件が完了したわよ"
vp "統合テスト5件が完了したわよ"

# ファイル操作の完了
vp "設定ファイルの読み込みが完了したわよ"
vp "ログファイルの作成が完了したわよ"
vp "出力ファイルの書き込みが完了したわよ"
```
