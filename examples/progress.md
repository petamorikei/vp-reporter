# 進捗報告の例

作業の進捗状況を報告する際の音声報告の例です。

## 基本的な進捗報告

**重要**: 抽象的な表現は避け、具体的な作業内容を述べます。

```bash
vp "コンパイルが完了しました"
vp "ビルドが半分完了しました"
vp "エーピーアイ接続に成功しました"
vp "パッケージのインストールが完了しました"
```

## より詳細な進捗報告

```bash
vp "設定ファイルを作成しました"
vp "データベース接続に成功しました"
vp "ユニットテストに合格しました"
vp "依存関係のインストールが完了しました"
```

## 段階的な進捗報告

```bash
vp "コンパイルが完了しました"
vp "テストが完了しました"
vp "パッケージングを開始します"
```

## 技術用語をカタカナ変換した例

| 英語 | カタカナ表記 | 使用例 |
|------|------------|--------|
| compile | コンパイル | `vp "コンパイルが完了しました"` |
| install | インストール | `vp "インストールが完了しました"` |
| download | ダウンロード | `vp "ダウンロードが完了しました"` |
| upload | アップロード | `vp "アップロードが完了しました"` |
| API | エーピーアイ | `vp "エーピーアイの接続に成功しました"` |
| database | データベース | `vp "データベースの設定が完了しました"` |
| cache | キャッシュ | `vp "キャッシュのクリアが完了しました"` |
| Docker image | ドッカーイメージ | `vp "ドッカーイメージのビルドが完了しました"` |
| TypeScript | タイプスクリプト | `vp "タイプスクリプトのコンパイルが完了しました"` |

## 数値を含む進捗報告

```bash
vp "テストが5件完了しました"
vp "ビルドが80パーセント完了しました"
vp "残り3ファイルです"
```


## 複雑な処理の進捗報告

```bash
vp "データベースマイグレーションが完了しました"
vp "ノードモジュールのインストールが完了しました"
vp "統合テストが成功しました"
vp "エーピーアイの統合が完了しました"
```

## 使用上の注意

- **オプションは使用しない**: `vp "メッセージ"`の形式のみを使用
- **基本は1文で簡潔に**: 進捗報告は基本的に1文で簡潔に（10〜20文字程度が理想）
- **具体的な内容を含める**: 「処理」「タスク」などの抽象的な表現は避ける
- **事実を淡々と述べる**: 感情表現は不要。起きた事実のみを報告
- 何が完了したのかを明確に伝える
- 英語の技術用語は必ずカタカナに変換
- 数値を含める場合は自然で短い表現にする
