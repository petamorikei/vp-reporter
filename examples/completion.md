# タスク完了時の報告例

作業が完了した際の音声報告の例です。

## 基本的な完了報告（1文、簡潔に）

**重要**: 何が完了したのかを具体的に述べます。

```bash
vp "ビルドが完了したわよ"
vp "全テストが完了したわよ"
vp "デプロイが完了したわよ"
vp "コンパイルが完了したわよ"
```

## 詳細な完了報告（複数文、最大140字程度）

内容を十分に伝える必要がある場合は、複数文で詳細を報告できます。

```bash
vp "ビルドが完了したわよ。15個のファイルをコンパイルして、バンドルサイズは2メガバイトね。エラーはなかったわよ"
vp "全てのテストが完了したわよ。ユニットテスト50件、統合テスト20件が全て合格したわね。実行時間は3分だったわよ"
vp "本番環境へのデプロイが完了したわよ。3つのサービスを起動して、ヘルスチェックに合格したわね。ロールバックの準備も完了しているわよ"
vp "タイプスクリプトのコンパイルが完了したわよ。120個のファイルを処理して、型エラーはなかったわね"
```

## 技術用語をカタカナ変換した例

| 英語 | カタカナ表記 | 使用例 |
|------|------------|--------|
| build | ビルド | `vp "ビルドが成功したわよ"` |
| test | テスト | `vp "全てのテストに合格したわよ"` |
| deploy | デプロイ | `vp "デプロイが完了したわよ"` |
| compile | コンパイル | `vp "コンパイルが成功したわよ"` |
| install | インストール | `vp "インストールが完了したわよ"` |
| setup | セットアップ | `vp "セットアップが完了したわよ"` |
| migration | マイグレーション | `vp "マイグレーションが完了したわよ"` |
| CI/CD | シーアイシーディー | `vp "シーアイシーディーが成功したわよ"` |
| Docker | ドッカー | `vp "ドッカーのセットアップが完了したわよ"` |

## より詳細な完了報告

```bash
vp "ユニットテストが全て完了したわよ"
vp "ログインバグを修正したわよ"
vp "データベースバックアップが完了したわよ"
vp "開発サーバーが起動したわよ"
vp "認証機能の実装が完了したわよ"
```

## 使用上の注意

- **オプションは使用しない**: `vp "メッセージ"`の形式のみを使用
- **基本は1文、必要に応じて複数文**: 簡潔な報告は1文で。内容を十分に伝える必要がある場合は複数文で詳細を報告（最大140字程度）
- **具体的な内容を含める**: 「完了しました」だけでなく、何が完了したのかを明確に
- **事実を淡々と述べる**: 感情表現は不要。起きた事実のみを報告
- **夏色花梨の口調**: 完了報告は「〜したわよ」、状態・考察は「〜ね」「〜わね」を使用
- **詳細報告の場合**: 何をしたか、結果はどうだったか、重要な数値や状態を含める
- 英語の技術用語は必ずカタカナに変換
