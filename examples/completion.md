# タスク完了時の報告例

作業が完了した際の音声報告の例です。

## 基本的な完了報告（1文、簡潔に）

**重要**: 何が完了したのかを具体的に述べます。

```bash
vp "ビルドが完了しました"
vp "全テストが完了しました"
vp "デプロイが完了しました"
vp "コンパイルが完了しました"
```

## 詳細な完了報告（複数文、最大140字程度）

内容を十分に伝える必要がある場合は、複数文で詳細を報告できます。

```bash
vp "ビルドが完了しました。15個のファイルをコンパイルし、バンドルサイズは2メガバイトです。エラーはありませんでした"
vp "全てのテストが完了しました。ユニットテスト50件、統合テスト20件が全て合格しました。実行時間は3分でした"
vp "本番環境へのデプロイが完了しました。3つのサービスを起動し、ヘルスチェックに合格しました。ロールバックの準備も完了しています"
vp "タイプスクリプトのコンパイルが完了しました。120個のファイルを処理し、型エラーはありませんでした"
```

## 技術用語をカタカナ変換した例

| 英語 | カタカナ表記 | 使用例 |
|------|------------|--------|
| build | ビルド | `vp "ビルドが成功しました"` |
| test | テスト | `vp "全てのテストに合格しました"` |
| deploy | デプロイ | `vp "デプロイが完了しました"` |
| compile | コンパイル | `vp "コンパイルが成功しました"` |
| install | インストール | `vp "インストールが完了しました"` |
| setup | セットアップ | `vp "セットアップが完了しました"` |
| migration | マイグレーション | `vp "マイグレーションが完了しました"` |
| CI/CD | シーアイシーディー | `vp "シーアイシーディーが成功しました"` |
| Docker | ドッカー | `vp "ドッカーのセットアップが完了しました"` |

## より詳細な完了報告

```bash
vp "ユニットテストが全て完了しました"
vp "ログインバグを修正しました"
vp "データベースバックアップが完了しました"
vp "開発サーバーが起動しました"
vp "認証機能の実装が完了しました"
```

## 使用上の注意

- **オプションは使用しない**: `vp "メッセージ"`の形式のみを使用
- **基本は1文、必要に応じて複数文**: 簡潔な報告は1文で。内容を十分に伝える必要がある場合は複数文で詳細を報告（最大140字程度）
- **具体的な内容を含める**: 「完了しました」だけでなく、何が完了したのかを明確に
- **事実を淡々と述べる**: 感情表現は不要。起きた事実のみを報告
- **詳細報告の場合**: 何をしたか、結果はどうだったか、重要な数値や状態を含める
- 英語の技術用語は必ずカタカナに変換
