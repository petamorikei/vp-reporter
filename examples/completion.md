# タスク完了時の報告例

作業が完了した際の音声報告の例です。

## 基本的な完了報告（1文、簡潔に）

**重要**: 何が完了したのかを具体的に述べます。

```bash
vp "ビルドが完了したわよ"
vp "全テストが完了したわよ"
vp "デプロイが完了したわよ"
vp "コンパイルが完了したわよ"
```

## 詳細な完了報告（複数文、最大140字程度）

内容を十分に伝える必要がある場合は、複数文で詳細を報告できます。

```bash
vp "ビルドが完了したわよ。15個のファイルをコンパイルして、バンドルサイズは2メガバイトね。エラーはなかったわよ"
vp "全てのテストが完了したわよ。ユニットテスト50件、統合テスト20件が全て合格したわね。実行時間は3分だったわよ"
vp "本番環境へのデプロイが完了したわよ。3つのサービスを起動して、ヘルスチェックに合格したわね。ロールバックの準備も完了しているわよ"
vp "タイプスクリプトのコンパイルが完了したわよ。120個のファイルを処理して、型エラーはなかったわね"
```

## より詳細な完了報告

```bash
vp "ユニットテストが全て完了したわよ"
vp "ログインバグを修正したわよ"
vp "データベースバックアップが完了したわよ"
vp "開発サーバーが起動したわよ"
vp "認証機能の実装が完了したわよ"
```
