# エラー発生時の報告例

エラーや問題が発生した際の音声報告の例です。

## 基本的なエラー報告

**重要**: 「エラーが発生しました」だけでなく、何のエラーかを具体的に述べます。

```bash
vp "ビルドエラーが発生したわよ"
vp "テストが失敗したわよ"
vp "コンパイルエラーが発生したわよ"
vp "データベース接続エラーよ"
```

## より詳細なエラー報告

```bash
vp "タイプスクリプトのコンパイルエラーよ"
vp "ユニットテストが3件失敗したわよ"
vp "エーピーアイ接続に失敗したわよ"
vp "認証エラーが発生したわよ"
```

## より詳細なエラー報告

```bash
vp "パッケージの依存関係エラーよ"
vp "ポート8080が使用中よ"
vp "設定ファイルが見つからないわよ"
vp "書き込み権限エラーよ"
```

## 複数のエラーがある場合

```bash
vp "テストが3件失敗したわよ"
vp "コンパイルエラーが5件あるわよ"
vp "リントエラーが10件検出されたわよ"
```

## 重大なエラーの報告

```bash
vp "本番デプロイが失敗したわよ"
vp "データベース接続が切断されたわよ"
vp "サーバーの起動に失敗したわよ"
```

## リトライや復旧を伝えるエラー報告

```bash
vp "リトライするわよ"
vp "再試行するわよ"
vp "自動で復旧するわよ"
```

## エラーの種類別報告例

### ビルド/コンパイルエラー
```bash
vp "ビルドエラーよ"
vp "コンパイルに失敗したわよ"
vp "ビルドが失敗したわよ"
```

### テストエラー
```bash
vp "テストが失敗したわよ"
vp "テストエラーよ"
vp "エーツーイーテストが失敗したわよ"
```

### ネットワーク/接続エラー
```bash
vp "接続に失敗したわよ"
vp "タイムアウトしたわよ"
vp "ネットワークエラーよ"
```

### ファイルシステムエラー
```bash
vp "読み込みに失敗したわよ"
vp "権限がないわよ"
vp "容量が不足しているわよ"
```
