# エラー発生時の報告例

エラーや問題が発生した際の音声報告の例です。

## 基本的なエラー報告

**重要**: 「エラーが発生しました」だけでなく、何のエラーかを具体的に述べます。

```bash
vp "ビルドエラーが発生しました"
vp "テストが失敗しました"
vp "コンパイルエラーが発生しました"
vp "データベース接続エラーです"
```

## より詳細なエラー報告

```bash
vp "タイプスクリプトのコンパイルエラーです"
vp "ユニットテストが3件失敗しました"
vp "エーピーアイ接続に失敗しました"
vp "認証エラーが発生しました"
```

## 技術用語をカタカナ変換した例

| 英語 | カタカナ表記 | 使用例 |
|------|------------|--------|
| build error | ビルドエラー | `vp "ビルドエラーが発生しました"` |
| test failure | テストの失敗 | `vp "テストが失敗しました"` |
| compile error | コンパイルエラー | `vp "コンパイルエラーが発生しました"` |
| syntax error | シンタックスエラー | `vp "シンタックスエラーが発生しました"` |
| connection error | 接続エラー | `vp "接続エラーが発生しました"` |
| timeout | タイムアウト | `vp "タイムアウトが発生しました"` |
| permission denied | 権限エラー | `vp "権限エラーが発生しました"` |
| API error | エーピーアイエラー | `vp "エーピーアイエラーが発生しました"` |
| database error | データベースエラー | `vp "データベースエラーが発生しました"` |


## より詳細なエラー報告

```bash
vp "パッケージの依存関係エラーです"
vp "ポート8080が使用中です"
vp "設定ファイルが見つかりません"
vp "書き込み権限エラーです"
```

## 複数のエラーがある場合

```bash
vp "テストが3件失敗しました"
vp "コンパイルエラーが5件あります"
vp "リントエラーが10件検出されました"
```

## 重大なエラーの報告

```bash
vp "本番デプロイが失敗しました"
vp "データベース接続が切断されました"
vp "サーバーの起動に失敗しました"
```

## リトライや復旧を伝えるエラー報告

```bash
vp "リトライします"
vp "再試行します"
vp "自動で復旧します"
```

## エラーの種類別報告例

### ビルド/コンパイルエラー
```bash
vp "ビルドエラーです"
vp "コンパイルに失敗しました"
vp "ビルドが失敗しました"
```

### テストエラー
```bash
vp "テストが失敗しました"
vp "テストエラーです"
vp "エーツーイーテストが失敗しました"
```

### ネットワーク/接続エラー
```bash
vp "接続に失敗しました"
vp "タイムアウトしました"
vp "ネットワークエラーです"
```

### ファイルシステムエラー
```bash
vp "読み込みに失敗しました"
vp "権限がありません"
vp "容量が不足しています"
```

## 使用上の注意

- **オプションは使用しない**: `vp "メッセージ"`の形式のみを使用
- **基本は1文で簡潔に**: エラー報告は基本的に1文で簡潔に（10〜20文字程度が理想）
- **具体的な内容を含める**: 「エラーが発生しました」だけでなく、何のエラーかを明確に
- **事実を淡々と述べる**: 感情表現は不要。起きた事実のみを報告
- 詳細な対応方法は文章で伝え、音声報告は簡潔に
- 英語の技術用語は必ずカタカナに変換
- エラーの種類を簡潔に伝える
- 自動リトライなどの対応を取る場合は「ビルドをリトライします」など具体的に
