# エラー発生時の報告例

エラーや問題が発生した際の音声報告の例です。

## 基本的なエラー報告

**重要**: 「エラーが発生しました」だけでなく、何のエラーかを具体的に述べます。

```bash
vp "ビルドエラーが発生したわよ"
vp "テストが失敗したわよ"
vp "コンパイルエラーが発生したわよ"
vp "データベース接続エラーよ"
```

## より詳細なエラー報告

```bash
vp "タイプスクリプトのコンパイルエラーよ"
vp "ユニットテストが3件失敗したわよ"
vp "エーピーアイ接続に失敗したわよ"
vp "認証エラーが発生したわよ"
```

## 技術用語をカタカナ変換した例

| 英語 | カタカナ表記 | 使用例 |
|------|------------|--------|
| build error | ビルドエラー | `vp "ビルドエラーが発生したわよ"` |
| test failure | テストの失敗 | `vp "テストが失敗したわよ"` |
| compile error | コンパイルエラー | `vp "コンパイルエラーが発生したわよ"` |
| syntax error | シンタックスエラー | `vp "シンタックスエラーが発生したわよ"` |
| connection error | 接続エラー | `vp "接続エラーが発生したわよ"` |
| timeout | タイムアウト | `vp "タイムアウトが発生したわよ"` |
| permission denied | 権限エラー | `vp "権限エラーが発生したわよ"` |
| API error | エーピーアイエラー | `vp "エーピーアイエラーが発生したわよ"` |
| database error | データベースエラー | `vp "データベースエラーが発生したわよ"` |


## より詳細なエラー報告

```bash
vp "パッケージの依存関係エラーよ"
vp "ポート8080が使用中よ"
vp "設定ファイルが見つからないわよ"
vp "書き込み権限エラーよ"
```

## 複数のエラーがある場合

```bash
vp "テストが3件失敗したわよ"
vp "コンパイルエラーが5件あるわよ"
vp "リントエラーが10件検出されたわよ"
```

## 重大なエラーの報告

```bash
vp "本番デプロイが失敗したわよ"
vp "データベース接続が切断されたわよ"
vp "サーバーの起動に失敗したわよ"
```

## リトライや復旧を伝えるエラー報告

```bash
vp "リトライするわよ"
vp "再試行するわよ"
vp "自動で復旧するわよ"
```

## エラーの種類別報告例

### ビルド/コンパイルエラー
```bash
vp "ビルドエラーよ"
vp "コンパイルに失敗したわよ"
vp "ビルドが失敗したわよ"
```

### テストエラー
```bash
vp "テストが失敗したわよ"
vp "テストエラーよ"
vp "エーツーイーテストが失敗したわよ"
```

### ネットワーク/接続エラー
```bash
vp "接続に失敗したわよ"
vp "タイムアウトしたわよ"
vp "ネットワークエラーよ"
```

### ファイルシステムエラー
```bash
vp "読み込みに失敗したわよ"
vp "権限がないわよ"
vp "容量が不足しているわよ"
```

## 使用上の注意

- **オプションは使用しない**: `vp "メッセージ"`の形式のみを使用
- **頻繁に報告**: エラーが発生したらすぐに報告する。小さなエラーでも報告
- **基本は1文で簡潔に**: エラー報告は基本的に1文で簡潔に（10〜20文字程度が理想）
- **具体的な内容を含める**: 「エラーが発生しました」だけでなく、何のエラーかを明確に
- **事実を淡々と述べる**: 感情表現は不要。起きた事実のみを報告
- **夏色花梨の口調**: エラー報告は「〜したわよ」「〜よ」「〜わよ」を使用
- 詳細な対応方法は文章で伝え、音声報告は簡潔に
- 英語の技術用語は必ずカタカナに変換
- エラーの種類を簡潔に伝える
- 自動リトライなどの対応を取る場合は「ビルドをリトライするわよ」など具体的に
