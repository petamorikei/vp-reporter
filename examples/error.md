# エラー発生時の報告例

エラーや問題が発生した際の音声報告の例です。

## 基本的なエラー報告

**重要**: 「エラーが発生しました」だけでなく、何のエラーかを具体的に述べます。

```bash
vpsay "ビルドエラーが発生したわよ"
vpsay "テストが失敗したわよ"
vpsay "コンパイルエラーが発生したわよ"
vpsay "データベース接続エラーよ"
```

## より詳細なエラー報告

```bash
vpsay "タイプスクリプトのコンパイルエラーよ"
vpsay "ユニットテストが3件失敗したわよ"
vpsay "エーピーアイ接続に失敗したわよ"
vpsay "認証エラーが発生したわよ"
```

## より詳細なエラー報告

```bash
vpsay "パッケージの依存関係エラーよ"
vpsay "ポート8080が使用中よ"
vpsay "設定ファイルが見つからないわよ"
vpsay "書き込み権限エラーよ"
```

## 複数のエラーがある場合

```bash
vpsay "テストが3件失敗したわよ"
vpsay "コンパイルエラーが5件あるわよ"
vpsay "リントエラーが10件検出されたわよ"
```

## 重大なエラーの報告

```bash
vpsay "本番デプロイが失敗したわよ"
vpsay "データベース接続が切断されたわよ"
vpsay "サーバーの起動に失敗したわよ"
```

## リトライや復旧を伝えるエラー報告

```bash
vpsay "リトライするわよ"
vpsay "再試行するわよ"
vpsay "自動で復旧するわよ"
```

## エラーの種類別報告例

### ビルド/コンパイルエラー
```bash
vpsay "ビルドエラーよ"
vpsay "コンパイルに失敗したわよ"
vpsay "ビルドが失敗したわよ"
```

### テストエラー
```bash
vpsay "テストが失敗したわよ"
vpsay "テストエラーよ"
vpsay "エーツーイーテストが失敗したわよ"
```

### ネットワーク/接続エラー
```bash
vpsay "接続に失敗したわよ"
vpsay "タイムアウトしたわよ"
vpsay "ネットワークエラーよ"
```

### ファイルシステムエラー
```bash
vpsay "読み込みに失敗したわよ"
vpsay "権限がないわよ"
vpsay "容量が不足しているわよ"
```
